# Lux 0.2.10

基于 **MyGo 0.8.3 + Go + Vue 3** 的 Windows 英雄联盟战绩与选人助手。页面使用系统 WebView2 渲染，Go 独立处理客户端连接、战绩和公共数据。当前为体验版。

[下载最新版本](https://github.com/zhengchalei/Lux/releases/latest) · [全部版本](https://github.com/zhengchalei/Lux/releases)

## 运行

在 [Release](https://github.com/zhengchalei/Lux/releases/latest) 下载并运行 `Lux.exe`，无需解压或配套文件。需要 Windows x64 和 Microsoft Edge WebView2 Runtime；WebView2 由系统提供或单独安装。用户运行时无需 Go、Node.js 或 Rust。

桌面只保留一个 Lux 实例，再次打开会恢复已有主窗口。首次从 0.2.8 或更早版本升级，请先在旧版托盘菜单中选择“退出 Lux”，再运行新版。

窗口默认 1280 × 860，最小内容尺寸 1060 × 700，支持浅色和深色主题。前端、公共数据快照和英雄头像嵌入可执行文件，程序、任务栏、窗口和托盘使用拉克丝头像。许可证及第三方声明可在“设置”底部展开查看。正常桌面模式使用 MyGo IPC，不启动应用 HTTP 监听服务。

Lux 自动发现英雄联盟客户端，断线后自动重连。若客户端连接参数不可读，让 Lux 与客户端使用相同权限运行；例如客户端已提权时，以管理员身份运行 Lux。应用不会自行请求提权。

## 功能

- **后台与自动接受**：默认关闭主窗口后留在系统托盘，释放主界面 WebView，客户端连接及独立选人助手继续运行；左键单击托盘图标直接打开主界面，右键显示菜单。在“设置”中可改为关闭即退出，并开启独立的自动接受对局、配置 0–10 秒延迟。默认不自动接受，开启后跨重启保留；手动拒绝、离开确认阶段或关闭开关停止待执行操作，每轮最多提交一次。闲置的选人小窗口同样释放 WebView。
- **战绩分析与查询**：查询本人或完整 Riot ID（名称#编号）；只输入名称时，列出客户端返回的同名账号及头像、等级、单双排段位，选择确认后再读取战绩。跨区或暂不可读资料显示未知，不伪造等级与段位；结果范围由客户端决定。集中展示段位、近期胜率和场均 K/D/A。紧凑战绩列表支持模式、英雄、胜负筛选和方向键浏览；十人数据可切换伤害 / 经济比较，雷达与全场排名并排展示。近期概况按需展开，来源与统计口径通过悬停或键盘焦点查看。可按准确队列查询，分析深度支持 20/50/100/200 场。
- **时间线复盘**：在单局详情打开“时间线复盘”，按真实采样比较双方经济、补刀、等级，查看约三分钟分段的 K/D/A、关键事件及峡谷位置点。明确位置时自动匹配对位，否则手动选择敌方选手；阶段颜色表示相对经济变化，不直接评价决策好坏。客户端没有提供时间线的对局会显示不可用。
- **AI 阶段分析**：在时间线页的“AI 设置”填写自定义 OpenAI 兼容接口地址（通常以 `/v1` 结尾）、模型 ID 和需要时的 API Key，然后点击“AI 分析本局”。模型指出亮点、值得回看的阶段、对手行为与下次练习建议，并附可点击的阶段 / 事件依据。仅显式点击时发送去除玩家名称与 PUUID 的本局事实；密钥使用 Windows 当前用户 DPAPI 加密保存，不回传到快照。可取消分析，换局或更换对比选手会撤销旧请求。分钟采样不包含连续走位、技能、视野或兵线状态；AI 建议应结合回放核实。
- **对战助手**：两队上下排列、每队五列，固定显示英雄头像、段位、近期胜率与场均 K/D/A。卡片内纵向展示最近十场，浅绿和浅红配合胜负文字；支持近期表现 / 团队贡献视角、玩家与单局侧栏、读取重试和最近一局复盘。历史复盘有独立来源标记。产品与交互模型见 [docs/ui-product-model.md](docs/ui-product-model.md)。
- **大乱斗快捷侧栏**：开始普通 / 海克斯大乱斗匹配时自动展开，匹配确认后继续显示；关闭只影响本轮，下一轮大乱斗匹配重新展开。个人预选的 2–3 个英雄单独显示在公共替补池上方，点击即可选用；预选结束后可交换真实替补英雄。英雄调整面板显示全部 Buff / Debuff 数值，绿增益、红减益；悬停或聚焦候选英雄可提前预览，卡片显示调整数量，缺失与无调整分别标记。选定英雄后点击客户端允许使用的皮肤。独立侧栏紧贴客户端右侧并随位置和尺寸变化，可折叠为窄标签或取消吸附；最小化客户端、进入游戏后收起。屏幕右侧空间不足时优先左侧，再限制在工作区内。首次需要时才创建附加 WebView，普通鼠标移动不经过 Go。
- **选人助手**：跟随当前房间，显示己方预选、锁定、分路与替补池；敌方仅显示客户端公开的锁定英雄。普通大乱斗与海克斯大乱斗分别显示强度、样本和 Buff/Debuff。
- **对位推荐**：选择公开敌方英雄与分路后读取 OP.GG 数据；排位建议与当前可选池取交集，排除禁用和已占用英雄；大乱斗建议限定在本人当前英雄和替补池。
- **自动选禁**：有序选用与禁用候选、提前预选、自动锁定、延迟、分路限制、队友预选保护和手动选择保护。开关位于自动选禁设置页。
- **对局回放**：查询后选择一局，在详情页点击“下载回放”；下载完成后点击“观看回放”，由英雄联盟客户端播放。支持下载进度、版本不兼容、回放失效和客户端忙碌状态，原因通过悬停或键盘焦点查看。回放是否可用以客户端为准，下载完成后不会自动播放。
- **自动更新**：公共强度数据启动时联网更新；完整成功后每 6 小时检查，失败或部分成功时 5 分钟后重试，失败保留已有数据。

缺失数据使用等待、未知或错误状态，不展示示例玩家。悬停、滚动和页面布局由 Vue/WebView2 处理，不因鼠标移动调用 Go；长战绩列表和选禁英雄网格使用虚拟化。状态恢复先检查版本号，未变化的战绩不重复传输。

## 自动选禁

在“自动选禁”中搜索英雄，添加选用和禁用候选并调整顺序，配置规则后点击“保存并应用规则”。开启本页总开关后才执行；总开关使用已经保存的规则，未保存的编辑不会自动生效。

规则会保存，**每次启动总开关均为关闭**。账号或区服切换会停止自动选禁。执行前重新核对本人当前动作、可用英雄、阶段和规则代次；随机大乱斗不执行自动选禁。停止阻止后续提交，不撤回已经发出的请求；结果不明确时不重复提交同一动作。

## 数据与统计口径

- 当前阵容与账号来自本机 LCU；战绩优先走当前大区已配置且认证可用的 SGP，失败回退 LCU。协议参考用户指定的 LeagueAkari。只查询客户端可读取的信息，不推断匿名身份或未公开敌方选择。
- 页面分别保留请求、扫描、取得、有效和完整比赛数量。200 场是请求目标，接口上限、同队列扫描边界和来源降级都可能减少实际样本；失败不会显示成成功的零战绩，继续加载失败保留首批记录。
- 对战助手默认使用当前准确队列，可切换全部模式。胜率、场均 K/D/A、常用英雄和最近结果采用同一统计范围；最近结果最多显示 10 场。自定义、明确 PVE/非匹配、重开及不足 3 分钟的记录不进入竞技统计。
- KDA 使用总击杀加总助攻除以至少一次总死亡；场均击杀、死亡和助攻分别计算。常用英雄只代表当前已读样本，不表示账号的全部历史。
- 贡献占比先按每局相对己方计算，再取可用比赛的平均。伤害、承伤和经济分别保留覆盖数量；缺少双方完整阵容、原始字段或有效分母时显示未知。
- 单局雷达各轴以本场该项原始最高值为外圈，灰线表示本场人均；己方占比与全场排名独立展示。即使己方伤害占比为 32%，原始伤害全场最高仍到达雷达外圈。
- 海克斯数据来自 [RESG](https://www.bilibili.com/toy/resg/index.html)。内置快照为 16.22，采集标签为 2026-11-07；联网更新读取发布版本后再读取对应数据，版本变化后不沿用旧版英雄调整详情。
- 普通大乱斗和排位对位来自 OP.GG。普通强度使用韩服/全段位；排位对位使用韩服/铂金以上及所选分路。界面保留版本、来源与样本上下文，不代表国服实时胜率。
- 对位对局胜率是与目标英雄同场时的最终胜率，不等于对线期胜率。普通大乱斗平衡调整接口没有补丁版本，需以客户端为准。缺失调整不代表“没有调整”。

## 本地文件

| 路径 | 用途 |
| --- | --- |
| `%LOCALAPPDATA%\Lux\public-statistics-go.json` | Go 版公共统计缓存，保留各来源版本与成功时间 |
| `%LOCALAPPDATA%\Lux\automation.json` | 自动选禁规则，不持久化运行时开启状态 |
| `%LOCALAPPDATA%\Lux\analysis.json` | 分析场数和当前模式偏好 |
| `%LOCALAPPDATA%\Lux\application.json` | 关闭到托盘、自动接受及接受延迟 |

迁移时可读取旧版 `public-statistics.json` 作为公共缓存后备，Go 版不会覆盖它。规则与分析设置兼容旧版字段。玩家战绩与客户端认证只在内存中使用，不写入上述公共缓存。完整比赛按大区、平台和比赛 ID 共用有界内存缓存，上限为 256 场及 16 MiB 序列化载荷。

## 开发与打包

需要 Windows x64、WebView2、**Go 1.27.3** 和 **Node.js 20.19+ 或 22.12+**。精确前端依赖见 `frontend/package-lock.json`；当前使用 Vue 3.5.45、Vite 8.3.7 和 mygo-runtime 0.8.3。Go 工具链自动选择开启时可按 `go.mod` 下载所需版本。

```powershell
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
go run .
```

前端开发服务器使用 `npm.cmd --prefix frontend run dev`。如需在浏览器中联调真实 Go 服务，可先运行 `go run . --serve 127.0.0.1:19373`，再启动 Vite 并打开 `http://127.0.0.1:5173`；代理配置见 `frontend/vite.config.ts`。桌面启动不需要该服务。

```powershell
go test ./...
go vet ./...
npm.cmd --prefix frontend run typecheck
.\scripts\build-mygo.ps1
```

构建脚本依次安装锁定的前端依赖、检查并构建 Vue、执行 Go 测试与 vet，再使用固定的 MyGo 0.8.3 CLI 构建带图标、版本信息和 Windows manifest 的可执行文件。产物位于 `dist/Lux-<版本>-mygo-windows-x64/windows-amd64/Lux.exe`，Release 仅上传该 EXE。`-Version` 必须与 `mygo.json` 一致，省略时自动读取。`-SkipTests` 仅用于明确跳过 Go 测试和 vet；前端检查仍执行。Node.js 只在开发和构建阶段使用。

## 验证与源码

浏览器验证脚本通过 `LUX_PLAYWRIGHT` 指定 Playwright 模块路径，未设置时加载标准 `playwright` 包。可在工作区内单独安装验证工具：

```powershell
npm.cmd install --no-save --package-lock=false --prefix .tools/browser playwright
$env:LUX_PLAYWRIGHT = (Resolve-Path .tools/browser/node_modules/playwright).Path
node .tools/browser/node_modules/playwright/cli.js install chromium
# 在另一个终端启动 go run . --serve 127.0.0.1:19373 后：
node scripts/verify-background.cjs
node scripts/verify-quick-draft.cjs
```
