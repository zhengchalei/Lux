原生事件限定同一 Windows 账号，并允许普通进程唤起已提权实例；本次进程验证使用相同权限。首次升级需退出不支持此机制的 0.2.8 及更早版本。

## 0.2.8 后台、自动接受与英雄调整

2026-11-11，Go 全量测试、vet、Vue 类型检查与生产构建通过。

- `scripts/verify-background.cjs` 使用隔离的渲染桥验证即时保存、独立开关、保存失败提示，以及两种尺寸和深浅主题，共四组布局。记录见 `artifacts/background/settings-report.json`。

- 实际桌面只读检查确认本机 LCU 已连接、托盘可用，客户端当时处于 `InProgress`。本轮保留用户前台游戏，不强制创建选人房间；线上自动接受、真实选人阶段 Buff 展示仍需下一次自然匹配核对。

窗口释放减少闲置渲染资源，不代表整个程序只保留一个进程。系统 WebView2、当前启用的小窗口和 Go 的有界业务缓存仍会占用内存；本次没有给出固定内存或帧率保证。

自定义 OpenAI 兼容 chat/completions 接口仅在用户点击分析后调用。发送匿名英雄阵容、当前玩家与所选对手的采样、阶段和事件；不发送玩家名称、PUUID、客户端认证或回放文件。API Key 用当前 Windows 用户 DPAPI 保护，公开设置仅返回密钥存在状态。模型结果按阶段和事件 ID 验证引用；此校验确认可追溯性，不保证战术解释正确。请求先注册独立取消标识，再进行客户端身份校验，避免早取消遗漏，以及旧面板取消新请求。

Go 回归覆盖不规则时间边界、事件不重复计数、明确角色匹配、模糊角色 / 大乱斗手动选择、缺失指标不填零、错玩家 / 比赛 / 区服 / 账号代数、缓存返回隔离、匿名请求构造、兼容接口 JSON、错误引用拒绝、服务失败脱敏、网络取消、加密密钥恢复 / 留空保留 / 显式清除，以及取消请求标识匹配和身份读取期间的早取消。

真实排位对局 901130065185 读取 29 帧、72 个支持事件、10 个阶段，查看玩家槽位 8、自动对位槽位 3。浏览器验证对手切换、曲线指标与阶段本地浏览、六种宽度 / 主题组合无横向溢出。独立本机模型 fixture 通过真实 Go HTTP 适配器与设置界面验证正常结果、依据定位、非法引用拒绝、显式取消与换局取消（4 个请求、2 次取消）；测试响应明确标为协议测试，不代表真实模型评价。测试配置保存在 artifacts/timeline/isolated-settings，不更改用户的 AI 配置。报告位于 artifacts/timeline/verification.json，截图区分 live-timeline 与 fixture-ai-result。

选中对局、时间线、回放与候选头像监听改为分别比较基础标识值，避免无关快照替换 account 对象时重新读取或撤销分析。浏览器回归会主动刷新同局详情触发新快照，确认阶段选择保留且没有额外时间线读取。
